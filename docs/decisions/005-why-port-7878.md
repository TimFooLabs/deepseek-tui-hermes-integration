# ADR-005: Why Port 7878

## Context

DeepSeek TUI's runtime API default port is **7878**. The initial plan suggested port 7777.

## Decision

Use the default port 7878.

## Rationale

- **7878 is the documented default** in `docs/RUNTIME_API.md`. No reason to change it.
- **7777 was an arbitrary choice** from the planning phase. Using non-default ports adds configuration overhead with no benefit.
- **No conflict**: Port 7878 was verified free on the target system.

## Consequences

- None. Using the default is the path of least resistance.

## Lesson

Always check the actual documentation before making configuration decisions. The plan's port number was a guess; the docs had the answer.
